# Commute Simulator v2.3 — SUUMOスクショ取り込み

GitHubで上書きするファイル:

- index.html
- css/style.css
- js/app.js

config.js とGoogle Maps APIキーは変更不要です。

## 操作フロー

1. 住所・施設・地図から出発地を決める
2. 候補に追加
3. 候補の「物件プロフィール」を開く
4. 「SUUMOスクショから入力」→「スクショを選ぶ」
5. SUUMOアプリ等のスクリーンショットを選択
6. OCR結果が既存フォームへ反映される
7. 内容を確認・修正
8. 「保存」

OCR結果だけでは自動保存しません。

## 自動抽出対象

- 家賃
- 管理・共益費
- 専有面積
- 間取り
- 築年数
- 駅アクセス（複数）
- 駐車場（明示された場合のみ）

読み取れなかった項目は空欄のままです。

## 複数の駅アクセス

例:
- JR東海道本線 / 戸塚駅 / 徒歩10分
- ブルーライン / 戸塚駅 / 徒歩12分

複数件を読み取った場合はすべてプロフィール内に保持します。

初期状態:
- 徒歩時間が最短のアクセスを評価用に選択

変更:
- 別路線へ切替可能
- 「手入力を使う」へ切替可能

総合スコアの「駅徒歩」には選択中の評価用アクセスを使います。

「駅徒歩」欄を直接編集すると自動的に「手入力を使う」へ切り替わります。

## OCR方式

Tesseract.js v7を必要時だけブラウザへ読み込みます。

- バックエンド不要
- Commute Simulatorからスクショをサーバーへアップロードしない
- OCRエンジン / 日本語・英語モデルは初回利用時にダウンロード
- jpn + eng で認識
- jsDelivrから読み込み、失敗時はunpkgへフォールバック

## 注意

OCRは100%ではないため、保存前に必ず確認してください。

特に確認推奨:
- 金額
- 小数点
- 専有面積
- 路線名
- 駅名
- 徒歩分数

「駐輪場」を「駐車場」と誤判定しないよう、
駐車場は「駐車場」という語がある行だけ判定します。
