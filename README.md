# Commute Simulator v1.3.1 — 時間帯比較の拡大表示

GitHubで上書きするファイル:

- index.html
- css/style.css
- js/app.js

config.js とAPIキーは変更不要です。

## v1.3.1追加機能

- TIME MATRIXに「拡大表示」ボタンを追加
- 比較結果がある時だけボタンを表示
- PCでは大きなモーダルで表示
- スマホではほぼ全画面表示
- 拡大版でも
  - 選択した時刻
  - 各候補の所要時間
  - 平均
  - 最大
  - ブレ
  - 最短候補のハイライト
  - 比較サマリー
  を表示
- ×ボタンで閉じる
- Escキーで閉じる
- 背景クリックで閉じる
- 拡大表示は既存の比較結果を表示するだけ
- Routes APIの再取得は一切なし
