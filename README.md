# Commute Simulator v2.2.1 — 周辺検索精度改善 + 候補地点Google Maps

GitHubで上書きするファイル:

- index.html
- css/style.css
- js/app.js

config.js とAPIキーは変更不要です。

## 変更1: 周辺検索を1.5kmへ戻す

v2.2の3.0kmから、半径1.5kmへ戻しました。

総合スコアの周辺利便性も1.5km基準になります。

3km検索済みの旧結果はv2.2.1では「要再検索」になります。

## 変更2: Nearby Searchを2回に分割

1クリックで次の2検索を実行します。

### 生活施設
- スーパー
- コンビニ
- ドラッグストア
- ジム

### 交通施設
- 電車・地下鉄駅
- バス停

各検索は最大20件なので、
6カテゴリ全部を1回の最大20件に押し込む方式より取りこぼしを減らします。

API利用:
- 「周辺施設を検索」1回
- Nearby Search 2回

取得済み結果を見るだけ:
- Places API 0回

総合スコア計算:
- Places API 0回
- Routes API 0回

## 変更3: 候補地点をGoogle Mapsで開く

候補カードに

「地点をGoogleマップで見る」

を追加しました。

出発地点をAutocomplete検索から設定した場合は、
Google Placesから取得した formattedAddress を候補と一緒に保存し、
Google Maps検索にもその住所を優先して使用します。

例:
検索で「マリンレジデンス」を選択
→ formattedAddress を候補に保持
→ 「地点をGoogleマップで見る」
→ その住所をGoogle Mapsへ渡す

地図タップ、現在地、ドラッグなど住所情報がない地点では
ラベルまたは緯度経度へ自動フォールバックします。

候補と住所は従来通りsessionStorageだけに保存され、
タブを閉じると消えます。
