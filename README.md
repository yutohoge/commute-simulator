## 変更1: 周辺検索を3回に分割

検索半径は1.5kmのままです。

1回の「周辺施設を検索」操作で、Nearby Searchを以下の3グループに分けて実行します。

### 1. 生活施設
- スーパー
- コンビニ
- ドラッグストア
- ジム

### 2. 電車・地下鉄駅
- train_station
- subway_station
- light_rail_station

### 3. バス停
- bus_stop
- bus_station

これにより、バス停が近隣に多数ある地域でも、
鉄道駅が最大20件の検索結果から押し出される問題を避けやすくなります。

API利用:
- 周辺施設検索 1クリック
- Nearby Search 3回

取得済み結果の表示:
- Places API 0回

総合スコア計算:
- Places API 0回
- Routes API 0回

v2.2.1以前の周辺検索結果は「要再検索」として扱います。

## 変更2: 候補地点のGoogle Mapsリンクを修正

旧仕様:
1. 保存された住所
2. 候補ラベル
3. 候補名
4. 緯度経度

このため住所がない地図ピンでは、
「ピンを移動した出発地」などの汎用ラベルをGoogle Mapsが検索し、
全く別の同名・類似地点へ飛ぶことがありました。

新仕様:
1. 検索時に取得した正確な住所
2. 住所がない場合は緯度経度

候補名や「ピンを移動した出発地」のようなラベルは
Google Maps検索語に使用しません。

そのため、
- Places検索で選んだ地点 → 取得した住所
- 地図タップ / ドラッグ / 現在地 → 正確な緯度経度

でGoogle Mapsを開きます。
