config.js とAPIキーは変更不要です。

## v2.0追加機能

候補ごとに任意で物件プロフィールを登録できます。

入力項目:
- 家賃（万円/月）
- 管理・共益費（円/月）
- 専有面積（㎡）
- 間取り
- 築年数（直接入力）
- 駅徒歩（分）
- 駐車場（あり / なし / 不明）
- メモ

すべて任意入力です。
プロフィールを入力しなくても、従来の通勤時間・候補比較・TIME MATRIXはそのまま利用できます。

## 自動計算

家賃 + 専有面積:
- 1㎡あたり家賃

家賃 + 管理・共益費:
- 月額住居費

家賃 + 管理・共益費 + 専有面積:
- 実質住居費単価

## UI

- 候補カードは従来のコンパクト表示を維持
- プロフィールを入力すると家賃 / 面積 / 間取りを小さく表示
- 「物件プロフィール」を開くと詳細を表示
- 「プロフィールを入力 / 編集」から編集
- 入力内容は候補と同じくsessionStorageに保存
- タブを閉じると消える
- プロフィール編集ではRoutes APIを呼びません

## 既存候補との互換性

v1.xで保存されている候補には空のプロフィールを自動追加します。
既存の候補比較機能はそのまま動作します。
