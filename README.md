# Commute Simulator v1.2.1 — 比較時刻カスタマイズ

GitHubで上書きするファイル:

- index.html
- css/style.css
- js/app.js

config.js とAPIキーは変更不要です。

## v1.2.1

- 比較時刻を1〜3個まで自由設定
- デフォルト: 7:30 / 8:00 / 18:00
- 時刻の追加・削除
- デフォルトに戻す
- 同一時刻の重複を防止
- 時刻順に自動整列
- 比較表の時刻列を自動生成
- API最大回数を選択時刻数に応じて自動計算
- 時刻設定はsessionStorageへ保存
- タブを閉じると時刻設定も消える
- 時刻を変えると古い時間帯比較結果を自動クリア
- 候補を追加・削除しても古い比較結果を自動クリア
- Routes APIは一括比較ボタンを押したときだけ使用
