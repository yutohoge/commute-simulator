# Commute Simulator v1.2 — 時間帯比較

GitHubで上書きするファイル:

- `index.html`
- `css/style.css`
- `js/app.js`

`config.js` とAPIキーは変更不要です。

## 追加機能

- 保存候補を次の平日で一括比較
- 7:30 / 8:00 / 18:00
- 平均所要時間
- 最大所要時間
- 時間帯によるブレ
- 最短候補をハイライト
- API実行前に最大リクエスト数を表示
- ボタンを押した時だけAPIを使用
- 既存30分キャッシュを再利用
- 同時リクエストは最大4件
- 比較結果はこのタブ内だけ保存

例:
- 候補2件 → 最大6経路計算
- 候補5件 → 最大15経路計算
